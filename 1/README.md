# tehran-house-price-prediction
A Machine Learning project to predict house prices in Tehran using Decision-Tree Regressor
# پیش‌بینی قیمت مسکن در تهران 🏠

این پروژه یک مدل یادگیری ماشین برای تخمین قیمت آپارتمان در تهران است.

## ویژگی‌های مدل:
- **الگوریتم:** Decision Tree Regressor
- **داده‌ها:** شامل متراژ، تعداد اتاق، پارکینگ، انباری، آسانسور و محله.
- **نوآوری:** دسته‌بندی دستی بیش از ۱۵۰ محله بر اساس مناطق ۲۲گانه شهرداری برای بهبود دقت مدل.

## نحوه استفاده:
ابتدا کتابخانه‌های لازم را نصب کنید:
`pip install pandas scikit-learn`

سپس فایل نوت‌بوک را اجرا کنید.
